# My E-Portfolio

A professional, responsive e-portfolio website designed for ITCC302. This project showcases my academic journey, skills, and growth throughout the semester.

## 📋 Project Overview

This e-portfolio is a comprehensive web application that documents:
- **Home Page**: Introduction and overview of what the portfolio contains
- **Personal Information**: Background, interests, skills, and contact information
- **Prerequisites**: Foundation courses and preparatory knowledge
- **Preliminary Assessment**: Initial phase learning and achievements
- **Midterm Evaluation**: Progress assessment and mid-semester growth
- **Finals Portfolio**: Final projects and comprehensive end-of-semester evaluation

### Prerequisites
- No special software required - just a web browser
- Basic knowledge of HTML, CSS, and JavaScript for customization

1. **Clone or download the repository**
   ```bash
   git clone https://github.com/yourusername/jyvnn.github.io.git
   cd jyvnn.github.io
   ```

2. **Open in browser**
   - Simply open `index.html` in your web browser

1. Push your code to GitHub
2. Go to repository settings → Pages
3. Select the main branch as the source
4. Your site will be available at `https://yourusername.github.io`

## 🎯 Customization Guide

### Updating Your Information

1. **Name and Title**
   - Open each HTML file
   - Replace "Your Name" with your actual name
   - Update role and descriptions

2. **Color Scheme**
   - Edit `style.css`
   - Modify CSS variables at the top:
     ```css
     :root {
         --primary-color: #2c3e50;
         --secondary-color: #3498db;
         --accent-color: #e74c3c;
         /* ... more colors */
     }
     ```

3. **Personal Content**
   - Update personal information in `personal-info.html`
   - Modify prerequisite courses in `prerequisites.html`
   - Add your achievements in `prelim.html`, `midterm.html`, and `finals.html`

4. **Profile Picture**
   - Replace the emoji avatar with a real image
   - Create an `images` folder
   - Update the HTML to reference the image

### Adding New Sections

1. Create a new HTML file following the same structure
2. Add a navigation link in the `<nav>` section of all pages
3. Link it in the navigation menu

### Styling Customization

- **Typography**: Modify font sizes in CSS
- **Spacing**: Adjust padding and margins
- **Colors**: Update CSS variables
- **Hover Effects**: Modify transition properties
